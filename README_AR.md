# آيات – تطبيق Android

هذا مشروع Cordova يحوّل ملفات موقع **آيات** المرفقة إلى تطبيق Android حقيقي من النوع الهجين (Hybrid) دون إعادة كتابة HTML وCSS وJavaScript.

## محتويات التطبيق
- واجهة رئيسية وروابط واضحة لجميع الأقسام
- القرآن الكريم والبحث داخل السورة والتفسير والتلاوة واختيار خمسة قراء
- صفحة الأحاديث ومحتواها الأصلي
- صفحة السنن ومحتواها الأصلي
- شريط تنقل سفلي مناسب للموبايل وتعديل لمشكلة تبويب السنن
- شعار مخصص وأيقونات تثبيت وألوان مستوحاة من الموقع

**مهم:** القرآن والتفسير والملفات الصوتية يتم جلبها من الإنترنت. الأحاديث والسنن مخزنة في التطبيق وتعمل دون إنترنت بعد تثبيت التطبيق، لكن استخدام الخطوط الخارجية يحتاج اتصالاً في أول تشغيل.

## بناء APK من GitHub بدون تثبيت Android Studio على الكمبيوتر
إذا عندك حساب GitHub، تقدر تبني التطبيق على سيرفرات GitHub:
1. أنشئ **مستودع GitHub جديد**، ثم ارفع **محتويات مجلد `Ayat-Android-Cordova`** إلى جذر المستودع (ليس ملف ZIP وحده ولا المجلد الأب). تأكد أن مجلد `.github/workflows` تم رفعه أيضًا.
2. افتح تبويب **Actions** ثم اختر **Build Ayat Android APK** ثم **Run workflow**. قد تُطلب الموافقة على تفعيل Actions للمستودع.
3. بعد نجاح المهمة ادخل إلى سجل التشغيل، وفي قسم **Artifacts** نزّل **Ayat-Android-Debug-APK**.
4. فك ضغط ملف Artifacts وستجد ملف **`app-debug.apk`**. انقله لهاتفك وثبته.

تنبيه: هذه الخطوات تحتاج حساب GitHub وإنترنت، وقد تختلف الأزرار والخيارات مع تحديث الواجهة. وقد يفشل البناء إذا تغيّرت حزم البناء على GitHub؛ راجع سجل Actions في هذه الحالة. هذا إصدار **Debug** للتجربة، وليس حزمة موقعة للنشر في Google Play.

## خطوات بناء APK على Windows
1. ثبّت **Node.js (20.17+ أو 22.9+)** و **JDK 17**.
2. ثبّت **Android SDK** (من Android Studio أو أدوات SDK Command Line Tools) مع Android SDK Platform 36 وBuild Tools 36.x، واضبط `ANDROID_HOME` والـ `PATH`. تحتاج كذلك Gradle متوافقًا حسب Cordova 15.
3. فك الضغط عن الملف وافتح `Ayat-Android-Cordova`.
4. شغّل `BUILD_APK_WINDOWS.bat`؛ يحتاج اتصالًا بالإنترنت لتنزيل حزم Cordova ومكونات البناء.
5. ملف APK الناتج بعد نجاح البناء: `platforms/android/app/build/outputs/apk/debug/app-debug.apk`.
6. انقل APK للهاتف وثبته (قد يطلب الهاتف السماح بتثبيت تطبيقات من هذا المصدر).

### أو بالأوامر يدويًا
```bat
npm install
npx cordova platform add android@15.1.0
npx cordova requirements android
npx cordova build android --debug
```

لا يلزم فتح Android Studio إذا ثبتَّ Android SDK وGradle وJDK بالأوامر وجرى ضبط متغيرات البيئة بطريقة صحيحة، لكن إعداد SDK يدويًا قد يكون أصعب.

## نسخة PWA مباشرة بدون إنشاء APK
المجلد `www` جاهز ليُرفع على GitHub Pages أو استضافة HTTPS. بعد الرفع افتح رابط الموقع في Chrome على Android واختر القائمة ⋮ ثم "تثبيت التطبيق" إذا توفّر الخيار، أو "إضافة إلى الشاشة الرئيسية". هذه الطريقة تثبت نسخة ويب قابلة للتشغيل بواجهة مستقلة في المتصفحات الداعمة، **وليست ملف APK منفصلًا**.

## تنبيهات
- في هذا التسليم لم يُنشأ APK لأن بيئة الإنشاء لا تحتوي أدوات Android SDK والبناء اللازمة، ولم يتم اختبار التطبيق على جهاز أندرويد فعلي.
- ملف `777.html` و`a.js` لم يتم تضمينهما لأنهما صفحة كلمة مرور غير مرتبطة بالتطبيق، وبها كلمة مرور مضمنة في الكود ورابط إلى صفحة غير موجودة.
- النصوص الدينية نُقلت كما هي من المصدر ولم تخضع لتدقيق علمي؛ يجب التحقق من صحة ألفاظ الأحاديث ونسبتها ومراجعها قبل النشر العام.
- تطبيق Cordova/الموقع لا يتصل تلقائيًا بالتعديلات الجديدة على GitHub؛ تحديث الملفات المحلية داخل APK يتطلب إصدار نسخة جديدة.
- احرص على عدم نشر تطبيق بإذن نطاقات عام غير ضروري، ولا تستخدم شهادة توقيع Debug للنشر على متجر التطبيقات.
